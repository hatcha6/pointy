# «دفتر كروت» store listing

Screenshots and the app preview for the App Store and Google Play. Every
screen is the real app (release build on an iPhone 16 Pro, the iPhone Duo
simulator, a Pixel emulator) on the live shelf, with fake orders. Device
frames are Apple's own bezels (Apple Design Resources) and Google's own
Pixel 6 Pro art (Android device art generator). Apple's bezels are licensed
for Apple-platform mock-ups only, so they appear in the App Store set only.

Uploading both Duo sizes gives the product page Apple's «optimized for iPhone
Duo» badge. From April 2027 they are required for apps built with the
iOS 27.1 SDK.

The app preview has a silent stereo track, which Apple accepts. Set the
poster frame to about 0:14 (the code on the card).

دفتر كروت أسرع طريقة لشراء كروت الاتصالات والإنترنت في ليبيا.
