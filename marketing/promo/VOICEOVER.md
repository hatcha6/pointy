# Voiceover scripts — دفتر promo films

Arabic narration for the four 30-second films. Timecodes mark the frame the
matching on-screen caption starts, so a line read at that mark lands with the
text rather than behind it.

**Delivery:** calm and unhurried, not hype. The product's claim is that work
gets quieter, and the read should sound like that. Leave the last ~2.5s clean
for the brand card — the logo lands on its own.

**Pacing:** each line below fits its slot at a normal speaking rate. Where a
slot is tight the alternative short line is given.

## Notes for the recording session

- **Brand name** is pronounced *Daftar* (دَفْتَر). The assistant is *GPT* as
  shown on screen; don't translate it.
- **Currency** is read *دينار* — the films show د.ل.
- **الأرقام** on screen are western digits; read them in Arabic normally
  (٤٬٢٨٥٫٥٠ → «أربعة آلاف ومئتين وخمسة وثمانين»). No line requires reading a
  figure aloud, so this only matters if you ad-lib one.
- **Music** should sit under the read at roughly −18 dB and duck out entirely
  for the last 2.5 seconds so the brand card is silent or carries a single
  soft note.
- **Silence is fine.** There are deliberate gaps between captions; don't fill
  them.
